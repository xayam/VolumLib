# VolumLib:  russian library Librusec 

- Only russian books
- Only file sizes more than 100 KB
- Only format FB2.ZIP
- Only these genres: programming, math, science, fantasy, fantastic, popadansy, esoteric...
- For write on MicroSD card 128 GB
- For program FBReader and MyHomeLib
- For platform Android/iOS/Windows
- INPX file are included
- MyHomeLib.zip are included

# Requirements system

- Recommendation: CPU with 4-8 core
- Require: OS Windows 10/11 (tested only on Win11)
- Require: 64-bit OS
- Require: free HDD/SSD space ~ 128 GigaByte
- Require: keyboard/monitor/mouse

# For developer: Installation and Build library

- Install python 3.13.9 (tested only this version)
- Create virtual env, run command "python.exe -m venv venv"
- Activate venv, run command "venv/Scripts/activate.bat"
- Upgrade pip, run command "python.exe -m pip install -upgrade pip"
- Install requirements, run command "pip install -r requirements.txt"
- Download Librusec zips from this [torrent](https://rutracker.org/forum/viewtopic.php?t=5384939)
- Change settings of paths in file "/ui/volum/model/config.py"
- Run script "/ui/dev_update.py" with python in environment "venv"
- Check zip-files in output folder
